# 🇹🇷 Forecasting Turkey Monthly Inflation (Time Series)

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python&logoColor=white)
![Time-Series](https://img.shields.io/badge/Data_Science-Time_Series-F7931E?logo=python&logoColor=white)

An advanced time-series forecasting project predicting Turkey's monthly inflation using macroeconomic indicators.

## 💡 Overview
- **Objective:** Model and forecast highly volatile economic data.
- **Techniques:** ARIMA, SARIMA, and LSTM neural networks.
- **Business Value:** Forward-looking macroeconomic insights for investment and policy decisions.

## 🛠️ Tech Stack
- **Statistics:** Statsmodels, ARIMA
- **Deep Learning:** TensorFlow / Keras (LSTM)
- **Data:** Pandas, NumPy
