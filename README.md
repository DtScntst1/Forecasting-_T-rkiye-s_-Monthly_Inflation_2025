# Forecasting Turkey's Monthly Inflation (Time Series)

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python&logoColor=white)
![Time-Series](https://img.shields.io/badge/Data_Science-Time_Series-F7931E?logo=statsmodels&logoColor=white)

An advanced time-series forecasting project aiming to predict Turkey's monthly inflation rates using historical macroeconomic indicators.

## Overview
Objective: To model and forecast highly volatile economic data using advanced statistical and machine learning methods.
Techniques: ARIMA, SARIMA, and LSTM neural networks for time-series predictions.
